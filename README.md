## Selected work

### Engineering Behavior Observatory

**Inspect how an engineering agent worked.**

Captures native agent sessions and workspace changes, with evidence-linked assessments for investigating failures and comparing runs.

[Code](https://github.com/trilogy-group/engineering-behavior-observatory) · [Project site](https://trilogy-group.github.io/engineering-behavior-observatory/)

### OpenSymphony

**Coordinate coding agents around real engineering work.**

Connects Linear issues to isolated workspaces and coding-agent runtimes, with dependency scheduling and human review.

[Code](https://github.com/kumanday/OpenSymphony) · [Website](https://opensymphony.dev/)

### Media Tooling

**Turn source recordings into editing material.**

Produces timestamped transcripts, subtitles, contact sheets, production plans, and first-pass rough cuts from audio and video.

[Code](https://github.com/kumanday/media-tooling)

### TTV Pipeline

**Build video-generation workflows around planned segments.**

Generates video through keyframe and frame-chaining workflows, with configurable local and cloud backends.

[Code](https://github.com/trilogy-group/ttv-pipeline)
